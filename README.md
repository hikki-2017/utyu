# 宇宙の目 × INNER COSMOS

**外の宇宙を観測する目と、内の宇宙が鳴る音。**
実在の衛星・気象・軌道データで地球から138億光年までを観測し、その観測が、あなたの1週間でできた宇宙に星を生む1つのWebアプリ。

## すぐ動かす

```bash
npm start   # http://localhost:8080
```

APIキー不要・ビルド不要。通信が切れてもサンプルデータで起動します（PWA）。

## 6つのモード（ヘッダーで切替）

| | モード | 内容 |
|---|---|---|
| 🌍 | 地球 | 台風・山火事・洪水・猛暑の72時間先リスクを3D地球儀に。ISSもリアルタイム |
| 🪐 | 太陽系 | 実軌道で8惑星を配置。太陽の宇宙天気はライブ。惑星の天気まとめ・年表 |
| 🌌 | 宇宙 | 近傍の恒星→天の川→銀河→観測可能な宇宙まで4段階 |
| 🔭 | 今夜の空 | 観測スコア、ISS通過予定、全天図、流星群 |
| 🌙 | 月面 | NASA月探査機の実画像に着陸実績と南極の水氷候補 |
| 🌠 | 僕の宇宙 | 一文を入れると1週間が宇宙に。重力・ブラックホール・音 |

## 本作の核：2つの宇宙をつなぐ

台風が発生した／災害リスクが上がった／ISSが通過した／太陽が荒れた——その**実イベントが起きるたび、「僕の宇宙」に星が1つ実際に生まれます**（`web/app.js` の `pushInner()` → `web/inner.html` の `applyReal()`）。演出ではなく、実データ由来の恒久的な星です。

---

AI × 衛星データで、山火事・洪水／土砂・猛暑の **72時間先リスク** を地図で見るハッカソン用プロトタイプ。

- 地図: NASA GIBS（BlueMarble・MODIS 実写・VIIRS 熱異常=火点）を MapLibre GL の3D地球儀（globe）に表示。ドラッグで回転、ホイールでズーム
- 気象: Open-Meteo（APIキー不要）。取得失敗時は決定論的サンプルデータで動作（画面右上に表示）
- リスクモデル: `web/model.js`。ブラウザ内で動く説明可能なロジスティックモデル（根拠の寄与を表示）。**学習・検証済みではない参考値**
- 予測API: `GET /api/risk?lat=35.99&lon=139.08`（72時間分の指数とレベル）
- 太陽系ビュー（ヘッダーの「🪐 太陽系」）: Three.js の3D太陽系。JPL近似軌道要素で選択日の惑星位置を計算（日付スライダーで±3年）。惑星ごとに気象の基準データ、火星は季節Ls・砂嵐シーズン、地球からの通信遅延を表示。太陽はNOAA SWPCのライブ宇宙天気（フレア・太陽風・Kp）と、太陽風が各惑星に届く日数
- 注意: 地球以外にリアルタイム気象観測はありません。惑星の値は文献ベースの基準値で、テクスチャは手続き生成（地球のみNASA画像）
- 宇宙ビュー（「🌌 宇宙」）: 近傍の恒星 → 天の川銀河 → 近傍の銀河 → 観測可能な宇宙の4段階の3Dマップ。星・銀河は実際の座標と距離（概数、対数スケール）。天の川の渦巻と宇宙の網目は模式図。系外惑星の天気（HD 189733b のガラスの雨など）も掲載
- 今夜の空（「🔭 今夜の空」/ AstroMatch風）: 地点ごとに雲量・月明かり・暗さから観測スコアを算出。CelesTrak の軌道データで ISS など明るい衛星の今夜の通過予定、太陽・月・惑星・衛星を描く全天図（時刻スライダー）、次の流星群、全国の雲が少ない地点、「北へ17km移動すると雲が減る」等のピンポイント提案。光害は未対応
- 月面（「🌙 月面」/ Lumina Terra風）: NASA LRO 全球モザイク上の3D月に、着陸実績と南極の水氷候補（シャクルトン等）を表示。永久日照・探査競合の詳細データは未対応
- ISS: 地球画面で位置・軌道・可視範囲をリアルタイム表示
- オフライン: PWA（Service Worker）。通信なしでもサンプルデータで起動
- シナリオ再生: 最大リスク地点を自動選択し、警報→消防提案→避難支援を再現

## ローカル実行

```bash
npm start          # http://localhost:8080
npm test
```

## デプロイ

| 方法 | 手順 | API |
|---|---|---|
| Docker / Render / Fly.io | `docker build -t earth-eye . && docker run -p 8080:8080 earth-eye`。Render は `render.yaml` を Blueprint として読み込み | あり |
| Vercel / Netlify / GitHub Pages（静的） | `web/` を公開ディレクトリに（設定済み）。Pages は `.github/workflows/pages.yml` を main に push | なし（画面は全機能動作） |

`vercel --prod` / `netlify deploy --prod --dir web` でも可。

## 注意

公的な警報ではありません。Open-Meteo 無料枠は非商用利用向けです。事業化する場合は有料プランまたは自前データ基盤へ。
